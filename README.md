# 🚀 DevsOnDeck

DevsOnDeck is a full-stack web application designed to connect developers with organizations based on their technical skills.

The platform allows developers to create an account, build their profile, select their top skills, and discover relevant job opportunities. Organizations can create accounts, publish job positions, define the required skills, and find developers whose profiles match their needs.

## ✨ Features

- 👨‍💻 Developer and Organization accounts
- 🔐 Secure authentication with email and password
- 🔑 Google Sign-In
- 📝 Developer profile and skills management
- 💼 Job position creation
- 🎯 Skill-based developer matching
- 📧 Automatic email notifications for matching opportunities
- 🗺️ Organization location displayed on a map
- ✅ Form validation and error handling

## 🛠️ Technologies Used

- **MongoDB / MongoDB Atlas** – Database
- **Express.js** – Backend and REST API
- **React.js** – Frontend
- **Node.js** – Server-side JavaScript
- **Mongoose** – MongoDB object modeling
- **Nodemailer** – Automatic email notifications
- **Google OAuth** – Google authentication
- **Git & GitHub** – Version control

## 🎯 How It Works

1. A developer creates an account and selects up to five technical skills.
2. An organization creates an account and publishes a job position.
3. The organization selects the skills required for the position.
4. DevsOnDeck compares the required skills with developer profiles.
5. Matching developers are displayed to the organization.
6. Developers can automatically receive an email when a matching opportunity is available.

## 📁 Project Structure

The application follows the MERN architecture with a clear separation between the React frontend and the Node.js/Express backend.
